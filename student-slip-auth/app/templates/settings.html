Security & Copy Resistance

How physical slip integrity is maintained against forgery

1. Server-Side Registration: Any fabricated or copied QR code not generated by this system and saved in the database returns INVALID SLIP.

2. 256-Bit Cryptographic Token: Each slip contains an unguessable high-entropy token stored only as a SHA-256 hash. Guessing an ID alone without the token fails.

3. The Physical Photocopy Threat: Because any paper printout can be photocopied with a Xerox machine, the administrator or proctor should use the Mark as Redeemed feature when collecting slips. If a photocopied duplicate is presented later, the scanner alerts ALREADY REDEEMED with the exact prior timestamp!
